# 数据字典（Data Dictionary）

对应文件：
- `ltci_policies_all.csv` — 全量 977 条
- `ltci_policy_documents.csv` — 其中「文件类型 = 政策文件」的 272 条（PMC 评价建议使用）
- `ltci_statistics.csv` — 分年度/层级/地区/类型统计

编码：UTF-8 with BOM（Excel 双击可直接打开）。文本字段中的政策原文含换行，读取时请保留引号解析（pandas 默认即可）。

---

## 字段说明

| 字段 | 类型 | 覆盖率 | 说明 |
|---|---|---|---|
| `政策标题` | 文本 | 100% | 取自网页 `<title>`，已去除网站后缀。部分页面标题缺失时回退为搜索引擎发现标题 |
| `文号` | 文本 | 40.3%（394/977） | 形如 `国医保发〔2020〕37号`。优先取页面「发文字号/文号」标注，其次在正文前 1500 字内正则匹配 |
| `发表时间` | 日期 `YYYY-MM-DD` | 95.0%（928/977） | 优先级：meta 发布日 → 页面「发布日期/成文日期」标注 → URL 日期 → 正文首个合法日期。已做合法性校验（1990–2036 年） |
| `发表主体` | 文本 | 66.9%（654/977） | 优先级：页面「发文单位/发文机关」标注 → 「来源：」标注（需含机构关键词）→ meta contentsource → 标题前缀推断（如「青岛市人民政府关于印发…」）；多部门联合发文的按标题识别完整机关序列 |
| `来源链接` | URL | 100% | 全部为 `*.gov.cn` 政府官方网站，已规范化为去跟踪参数形式 |
| `政策原文` | 长文本 | — | 网页正文纯文本。PDF/Word 附件已下载并抽取文本后合并；无法抽取的在 `备注` 注明 |
| `文件层级` | 枚举 | 100% | `国家级`(56) / `省级`(153) / `市级`(768)。依据发布域名与发现渠道判定 |
| `所属地区` | 文本 | 100% | 194 个地区，无缺失。国家级文件标注为 `国家层面` |
| `文件类型` | 枚举 | 100% | `政策文件`(272) / `政策解读`(269) / `新闻动态`(203) / `公示公告`(179) / `其他`(54)。按标题与正文关键词规则分类 |
| `备注` | 文本 | — | 抓取异常说明（附件解析失败、动态渲染页面等），正常为空 |

## 使用注意

1. **PMC 评价建议只用 `ltci_policy_documents.csv`（272 条政策文件）**。政策解读、新闻动态属于二次加工文本，不适合做政策工具编码。
2. 部分政策原文为空或偏短，是原页面采用 JS 动态渲染/正文为图片/实为栏目列表页所致，`备注` 已注明，需人工打开来源链接确认。
3. 同一政策可能存在多个官方转载版本，已按标题去重保留一条；但**修订前后不同版本均保留**（PMC 评价常需历年版本对比，请按 `发表时间` 排序后人工确认）。
4. 发表时间为空的 49 条、发表主体为空的 323 条，需人工回查来源链接补充。
5. 地区字段可能同时出现省级名与市级名（如「湖北」与「荆门」），做地区聚合时请注意层级。

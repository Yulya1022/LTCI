# LTCI — 中国长期护理保险政策文本语料库

爬取并整理中国**长期护理保险（长护险）**相关政策文本，用于政策文本量化研究（PMC 指数模型评价）。

## 快速开始（合作者请先读这里）

| 你想做什么 | 直接用这个文件 |
|---|---|
| 看总体情况、筛选浏览 | `长期护理保险政策文本汇总.xlsx`（4 个工作表，已配好筛选和冻结窗格） |
| 写代码做分析（Python / R / Stata） | `data/processed/ltci_policies_all.csv`（全量 977 条，UTF-8 BOM） |
| 直接做 PMC 指数评价 | `data/processed/ltci_policy_documents.csv`（272 条政策文件，建议只用这个） |
| 了解每个字段怎么来的、能不能信 | `data/processed/data_dictionary.md` |
| 看数据分布（年份/层级/地区/类型） | `data/processed/ltci_statistics.csv` |
| 写论文要一段完整的描述性统计 | `docs/描述性统计.md` |
| 想复现或继续扩充爬取 | `scripts/`（见下方「复现方式」） |

## 数据概况

| 项目 | 说明 |
|---|---|
| 政策条数 | **977 条** |
| 时间范围 | 2014-07-25 ~ 2026-10-28 |
| 数据来源 | 全部为政府官方网站（`*.gov.cn`）：经搜狗/必应/360 检索发现，并直爬国家医保局长护险专栏、中国政府网政策库 |
| 覆盖地区 | **194 个地区**（国家级 56 / 省级 153 / 市级 768） |
| 文件类型 | 政策文件 272 / 政策解读 269 / 新闻动态 203 / 公示公告 179 / 其他 54 |
| 字段完整度 | 发表时间 95.0%（928）· 发表主体 66.9%（654）· 文号 40.3%（394）· 政策原文 >100 字 88.3%（863） |
| 抓取底账 | 发现链接 1155 条 → 抓取成功 1133 条 → 相关性过滤与去重后 977 条 |

> **做 PMC 评价请用「政策文件」子集（272 条）**：发表时间覆盖 92%，发表主体覆盖 62%，可直接构建「政策文本—时间—主体—文号」四要素语料。

## 复现方式

```bash
pip install requests beautifulsoup4 lxml pandas openpyxl pypdf

python scripts/run_pipeline.py    # 三阶段流水线：发现 → 抓取 → 输出
python scripts/status.py          # 随时查看进度
python scripts/fetch_pages.py --redo-weak   # 补抓正文/主体/时间缺失的记录
```

三阶段均支持断点续爬：中断后重新运行即从断点继续，最多损失约 5 分钟进度。

## 已知限制

1. **49 条无发表时间**、**323 条无发表主体** —— 页面未提供相应标注，需人工回查来源链接。
2. **约 11% 的条目政策原文不足 100 字** —— 原页面为 JS 动态渲染、正文为图片或实为栏目列表页，`备注` 已注明。
3. **文件类型为规则自动分类**（272/269/203/179/54），边界样本可能误判，做精细编码前建议人工复核。
4. 个别政策有多个官方转载版本，已按标题去重；但修订前后版本均保留，用于政策变迁分析时请人工确认版本关系。
